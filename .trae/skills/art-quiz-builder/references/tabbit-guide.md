- 智能干扰项：WebSearch验证真实存在，与正确答案有共同特征

## 使用
1. 将完整 Prompt 复制到 Tabbit 妙招编辑器
2. 替换 \{管理员密码}\ 为实际 Supabase 密码
3. 运行妙招 → Agent 自动执行 → 在审核报告 Tab 审阅 → 确认批量发布
